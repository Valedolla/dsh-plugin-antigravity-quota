# dsh-plugin-antigravity-quota

Плагин для **DeepSeek Harness (DSH)**, обеспечивающий стабильную работу с моделями **Google AI Pro (Gemini 3.8 Flash, Claude и др.)** из РФ через локальный мост, DNS/SNI туннели и поддержку **GeoHide Smart DNS**.

---

## 🚀 Что нового в версии 1.6.0:
- **Пользовательские маршруты (Custom Routes)**: возможность добавлять свои серверы через интерфейс (Smart DNS, обычный DoH или SOCKS5-прокси от Xray/V2Ray/Karing) с быстрой проверкой связи перед сохранением и удалением в 1 клик.
- **Чистый список выбора**: удалены заведомо мёртвые шлюзы и заблокированные узлы. Оставлен надёжный базовый пул маршрутов.
- **Единая кнопка проверки**: одна удобная кнопка «⚡ Проверить выбранный маршрут (1 запрос)», тестирующая именно тот сервер, который выбран в выпадающем списке.
- **Автоматические краш-логи инцидентов (last-incident.json)**: при разрывах связи или региональных ошибках плагин мгновенно сохраняет снимок сбоя для быстрой диагностики.
- **Выделенная папка логов и кнопка «📁 Логи»**: кнопка в верхней панели открывает чистую папку %LOCALAPPDATA%\AGUnlocker\logs.
- **Горизонтальный 2-колоночный интерфейс**: пропорция 4:3 (~780 px) с аккуратным вертикальным скроллом, идеально помещающийся на экране.

---

## 🛠️ Архитектура системы
- **Порт 53130** — основной входящий CONNECT bridge (диспетчер маршрутов).
- **Порт 53129** — совместимый listener моста.
- **Порт 8317** — локальный сервис cli-proxy-api.exe (переводчик OpenAI -> Google Cloud Code).
- **Порт 43129** — локальный DNS/SNI форвардер g_dns.
- **Приоритет Auto**: GeoHide EU Smart DNS (https://eu.geohide.ru/dns-query) -> GeoHide US Smart DNS -> Comss.one -> WLRUS.

## 📦 Установка и обновление

### Вариант 1. Установка из готового архива (Рекомендуется)
1. Скачайте актуальный релизный архив dsh-plugin-antigravity-quota-1.6.0.tgz (или .zip) со страницы [Releases](../../releases).
2. Полностью закройте **DeepSeek Harness**.
3. Распакуйте содержимое архива в каталог плагина вашего профиля DSH:
   `	ext
   C:\Users\<Ваш_Пользователь>\.dsh\profiles\desktop\node_modules\dsh-plugin-antigravity-quota
   `
4. Убедитесь, что в файле package.json вашего профиля (~/.dsh/profiles/desktop/package.json) плагин указан в секциях dependencies и dsh.profile.bundles:
   `json
   "dependencies": {
     "dsh-plugin-antigravity-quota": "^1.6.0"
   },
   "dsh": {
     "profile": {
       "bundles": [
         "dsh-plugin-antigravity-quota"
       ]
     }
   }
   `
5. Запустите DeepSeek Harness. Виджет квот и маршрутов появится в правом нижнем углу интерфейса чата.

---

### Вариант 2. Автоматическое обновление через скрипт
В папке плагина есть готовый скрипт безопасной установки:
`powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "bin\install-active-profile.ps1"
`
Скрипт автоматически создаст резервную копию текущего плагина, проверит целостность и обновит активный профиль.
