# Antigravity Quota & Smart Routing Plugin for DeepSeek Harness

![Version](https://img.shields.io/badge/version-1.6.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-Windows%20x64-lightgrey.svg)
![Status](https://img.shields.io/badge/status-stable-success.svg)

Модульный плагин для расширения возможностей **DeepSeek Harness (DSH)** при работе с подпиской **Google AI Pro (Antigravity)**. Обеспечивает наглядный мониторинг квот моделей (Gemini 3.8 Flash, Gemini 3.1 Pro, Claude Opus 4.6, Claude Sonnet 4.6, GPT-OSS), удобное управление несколькими аккаунтами Google и отказоустойчивую маршрутизацию запросов через Smart DNS, DoH и локальные прокси-серверы.

---

## ⚡ Ключевые возможности

* **Интерактивный виджет в интерфейсе DSH**:
  * Кольцевые индикаторы использования лимитов в реальном времени (5-часовые и недельные окна).
  * Подробные таймеры до сброса квот с точностью до минут.
  * Мгновенное переключение между несколькими подключёнными Google-аккаунтами без перезапуска приложения.
  * Эргономичный двухколоночный интерфейс (4:3) с плавной прокруткой и компактным отображением информации.

* **Интеллектуальная маршрутизация (Failover Routing)**:
  * **Режим Auto**: интеллектуальное автопереключение между европейскими и американскими проксирующими DoH-узлами Smart DNS с автоматическим исключением временно недоступных серверов.
  * **Karing SOCKS5**: полная интеграция с внешними VPN/прокси клиентами (`127.0.0.1:3066`).
  * **Custom Routes (Пользовательские маршруты)**: возможность добавлять собственные серверы (Smart DNS, DoH, SOCKS5) прямо через графический интерфейс с предварительной проверкой доступности узла перед сохранением.

* **Надёжность и мониторинг**:
  * Встроенный тестовый механизм: проверка реальной генерации одним кликом без лишнего расхода квот.
  * Автоматическая фиксация аварийных событий в структурированном виде (`last-incident.json`) для мгновенной диагностики.
  * Быстрый доступ к папке логов прямо из шапки виджета.

## 🏗️ Архитектура компонентов

Плагин реализует локальный отказоустойчивый конвейер передачи данных:

```
[DeepSeek Harness]
       │
       ▼ (OpenAI ChatCompletions API)
[cli-proxy-api.exe :8317] ── (Авторизация OAuth2 & трансляция формата)
       │
       ▼ (HTTP CONNECT)
[xbox-failover-bridge :53130] ── (Диспетчер маршрутов & Failover)
       │
       ├─► GeoHide EU Smart DNS (:443)  [Приоритетный выход]
       ├─► GeoHide US Smart DNS (:443)  [Резервный Smart DNS]
       ├─► Пользовательские серверы     [SOCKS5 / DoH / Smart DNS]
       └─► Karing Proxy (:3066)         [Прямой SOCKS5 туннель]
```

* **`cli-proxy-api.exe` (`:8317`)** — локальный сервис-транслятор, преобразующий стандартные вызовы OpenAI API в протокол Google Cloud Code с бесшовным внедрением OAuth-токенов.
* **`xbox-failover-bridge` (`:53130`)** — локальный CONNECT-мост, отвечающий за выбор оптимального сетевого маршрута и разделение потоков (авторизация идёт напрямую, генерация — через туннели).
* **Совместимый слушатель (`:53129`)** — вспомогательный порт для совместимости со сторонними утилитами.

## 📦 Установка и обновление

### Вариант 1. Установка из готового архива (Рекомендуется)

1. Загрузите архив последней версии (`dsh-plugin-antigravity-quota-1.6.0.tgz` или `.zip`) со страницы [Releases](../../releases).
2. Завершите работу **DeepSeek Harness**.
3. Распакуйте архив в каталог плагинов активного профиля:
   ```text
   C:\Users\<Имя_Пользователя>\.dsh\profiles\desktop\node_modules\dsh-plugin-antigravity-quota
   ```
4. Убедитесь, что в конфигурационном файле `~/.dsh/profiles/desktop/package.json` плагин добавлен в списки зависимостей и бандлов:
   ```json
   {
     "dependencies": {
       "dsh-plugin-antigravity-quota": "^1.6.0"
     },
     "dsh": {
       "profile": {
         "bundles": [
           "dsh-plugin-antigravity-quota"
         ]
       }
     }
   }
   ```
5. Запустите DeepSeek Harness. Виджет квот и маршрутизации появится в правой нижней части панели диалога.

### Вариант 2. Автоматическое обновление скриптом

Если предыдущая версия плагина уже установлена, обновление можно выполнить входящим в комплект скриптом:
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "bin\install-active-profile.ps1"
```
Скрипт выполнит префлайт-проверку, создаст резервную копию текущего состояния и обновит файлы в профиле.

## 🔧 Диагностика и обслуживание

Для проверки состояния локальных служб и сетевой связности доступен автономный диагностический скрипт:
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "bin\diagnose-routing.ps1"
```

Скрипт проверяет:
- Привязку портов `53130`, `53129`, `8317` и `43129` к ожидаемым процессам;
- Согласованность адреса прокси в файлах конфигурации;
- Текущий активный транспорт и порядок приоритетов в режиме Auto;
- Доступность локального SOCKS5-прокси Karing.

## 🔒 Безопасность и конфиденциальность

- **Сквозное шифрование**: весь трафик к удалённым сервисам передаётся по протоколу TLS. Локальный мост выполняет прозрачную туннелизацию (TCP tunnel) и не расшифровывает пользовательские данные.
- **Изоляция авторизации**: запросы к эндпоинтам OAuth (`oauth2.googleapis.com`) передаются напрямую без промежуточных релеев во избежание сброса сессий.
- **Локальное хранение**: учётные данные и токены авторизации хранятся исключительно на локальном компьютере пользователя в системном профиле (`~/.cli-proxy-api`).
